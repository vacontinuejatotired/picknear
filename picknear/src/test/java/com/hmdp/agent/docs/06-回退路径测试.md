# 回退路径测试（阶段二 · 按需）

> 覆盖 `TaskExecutor` + `TaskQueue`（`@Deprecated`）。仅当 `feature.subagent.enabled=false` 逻辑变更时或修复回退路径 Bug 时生成。

---

## ⛔ 回退路径专属禁止

- **禁止在 TaskQueue 测试中真实操作数据库或 Redis**——SubTask 直接在内存中构造，`List.of(taskA, taskB)` 初始化
- **禁止在 TaskExecutor 测试中真实调用 ToolCallback**——用 `mock(ToolCallback.class)` + `when(callback.call(any(), any())).thenReturn("result")`
- **禁止验证 SseEmitter 推送格式**——那是阶段一的职责

## TaskQueue

```java
class TaskQueueTest {
    @Test void should_return_ready_tasks_when_no_dependency() { /* ... */ }
    @Test void should_return_ready_when_dependency_completed() { /* ... */ }
    @Test void should_return_ready_when_dependency_failed() { /* ... */ }
    @Test void should_not_return_ready_when_dependency_pending() { /* ... */ }
    @Test void should_mark_done_and_completed() { /* ... */ }
    @Test void should_mark_failed_and_increment_retry() { /* ... */ }
    @Test void should_check_all_done() { /* ... */ }
}
```

每个测试的构造方式：

```java
SubTask taskA = SubTask.builder().id("A").status(SubTaskStatus.PENDING).build();
SubTask taskB = SubTask.builder().id("B").status(SubTaskStatus.PENDING)
    .dependsOn(List.of("A")).build();
TaskQueue queue = new TaskQueue(List.of(taskA, taskB));

// A 完成后 B 才 READY
queue.markDone("A", "ok");
List<SubTask> ready = queue.getReadyTasks();
assertThat(ready).as("B 应就绪").hasSize(1);
assertThat(ready.get(0).getId()).isEqualTo("B");
```

## TaskExecutor

| # | 方法 | 条件 | 断言 |
|---|------|------|------|
| 1 | `should_execute_tool_call_successfully` | callback 返回 "ok" | COMPLETED，result="ok" |
| 2 | `should_mark_failed_when_tool_not_found` | toolName 不存在 | FAILED，result 含"未知工具" |
| 3 | `should_execute_llm_reason_with_context` | 有 COMPLETED 工具 | prompt 含工具结果 |
| 4 | `should_include_failed_tools_in_llm_reason` | 有 FAILED 工具 | prompt 含"以下步骤执行失败" |

```java
// ToolCall 成功
SubTask task = SubTask.builder().id("1").type(TaskType.TOOL_CALL).toolName("queryWeather").build();
when(weatherCallback.call(any(), any())).thenReturn("sunny");
executor.executeAll(queue);
assertThat(task.getStatus()).as("工具调用应成功").isEqualTo(SubTaskStatus.COMPLETED);
```
