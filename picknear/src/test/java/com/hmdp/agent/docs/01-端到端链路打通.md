```java
@BeforeEach
void setUp() {
    // (1) 异步同步化（核心技巧：反射替换线程池）
    ReflectionTestUtils.setField(aiService, "aiTaskExecutor",
            (Executor) Runnable::run);

    // (2) UserHolder（同步化后与异步 lambda 同线程）
    UserHolder.saveUserId(TEST_USER_ID);

    // (3) ChatClient 链
    lenient().when(chatClient.prompt()).thenReturn(chatClientRequestSpec);
    lenient().when(chatClientRequestSpec.user(any())).thenReturn(chatClientRequestSpec);
    lenient().when(chatClientRequestSpec.call()).thenReturn(chatClientResponseSpec);
    lenient().when(chatClientResponseSpec.content()).thenReturn(TEST_LLM_REPLY);

    // (4) Hook 链默认 PASS
    lenient().when(promptHookChain.execute(any(), any())).thenReturn(HookResult.pass());
    lenient().when(afterAiHookChain.execute(any(), any(), any())).thenReturn(HookResult.pass());

    // (5) responseRouter 默认无操作
    lenient().doNothing().when(responseRouter)
            .route(any(), any(), any(), any(), any());

    // (6) ChatMemory
    lenient().when(chatMemory.get(anyString())).thenReturn(List.of());
}

@AfterEach
void tearDown() {
    UserHolder.remove();
}
```

## 链路B：SSE 流式 + PASS（无规划）

### 被测方法

```java
void chatWithToolcall(String content, String conversationId, SseEmitter emitter);
```

### 代码生成清单

| # | 测试方法名 | 核心 Mock | 断言 |
|---|-----------|----------|------|
| 1 | `should_send_ai_reply_via_sse_when_after_hook_passes` | afterAiHook → PASS | `verify(afterAiHookChain).execute(...)` + `verify(responseRouter).route(...)` |
| 2 | `should_send_error_and_complete_when_hook_blocks` | promptHook → BLOCK | `verify(emitter).send(...)` + `.complete()`，router 不被调 |

| 4 | `should_push_friendly_error_when_all_retry_fail` | content() → 连续 3 次抛异常 | `verify(emitter, atLeast(2)).send(...)` + `.complete()` |
| 5 | `should_use_replaced_content_when_hook_replaces` | promptHook → REPLACE("替换内容") | `verify(requestSpec).user("替换内容")` |
| 6 | `should_set_conversation_id` | — | `verify(toolBeanCollector).setConversationId("my-session-id")` |

### 异步测试模板（必须用反射同步，不用 CountDownLatch）

```java
// 原理：setUp 中已把 aiTaskExecutor 替换为 Runnable::run
//       所以 chatWithToolcall 内部异步 lambda 变成同步执行
@Test
void should_send_ai_reply_via_sse_when_after_hook_passes() {
    SseEmitter emitter = mock(SseEmitter.class);       // ① mock，不是 new
    aiService.chatWithToolcall("你好", TEST_CONV_ID, emitter);  // ② 同步调用
    verify(responseRouter).route(any(), any(),            // ③ 直接 verify
            eq(TEST_LLM_REPLY), any(), eq(emitter));
}

// ⚠️ SseEmitter 必须 mock()，不能用 new：
//    mock 的 send() 不会真正写网络，我们可以 verify() 调用次数
//    new 的 SseEmitter.send() 会真正尝试写入，且 toString() 不暴露数据

// ⚠️ verify(emitter).send(any()) 有歧义（2 个重载），必须用：
//    any(SseEmitter.SseEventBuilder.class)
```

## 链路C：SSE 流式 + PLANNING → AiResponseRouter

链路 C 测试**独立的 AiResponseRouter**，不涉及 AiServiceImpl。Mock 配置独立：

```java
@ExtendWith(MockitoExtension.class)
class AiResponseRouterRouteTest {
    @Mock TaskPlanner taskPlanner;
    @Mock SseEmitter emitter;
    @InjectMocks AiResponseRouter router;
}
```

### 代码生成清单

| # | 测试方法名 | Decision | HookResult | 断言 |
|---|-----------|----------|-----------|------|
| 1 | `should_enter_task_planner_when_planning` | PLANNING | `HookResult.planningRequired()` | `verify(taskPlanner).planAndExecuteAsync(...)` |
| 2 | `should_push_error_when_block` | BLOCK | `HookResult.block("原因","hook")` | `verify(emitter).send(any SseEventBuilder)` + `.complete()` |
| 3 | `should_push_reply_when_pass` | PASS | `HookResult.pass()` | `verify(emitter).send(...)` + `.complete()` |
| 4 | `should_push_replaced_text_when_replace` | REPLACE | `HookResult.replace("新文本","hook")` | `verify(emitter).send(...)` + `.complete()` |
| 5 | `should_handle_emitter_send_exception` | PASS + send 抛异常 | `doThrow(IOException).when(emitter).send(...)` | 不抛异常，catch 后容错 |

> **注意**：SseEventBuilderImpl.toString() 不暴露实际数据，所以不能用 `argThat(d -> d.toString().contains(...))` 做内容匹配。
> 数据格式验证放在 `SseUtilsTest`（文档13）中覆盖。这里只验证 send() 被调用。

### AiResponseRouter 测试模板

```java
@Test
void should_enter_task_planner_when_planning() {
    router.route(HookResult.planningRequired(), "统计一下", "好的", ctx, emitter);
    verify(taskPlanner).planAndExecuteAsync(eq("统计一下"), eq("好的"), eq(ctx), eq(emitter));
    verifyNoInteractions(emitter);
}

@Test
void should_push_error_when_block() throws IOException {
    router.route(HookResult.block("安全拦截", "TestHook"), "输入", "回复", ctx, emitter);
    verify(emitter).send(any(SseEmitter.SseEventBuilder.class));
    verify(emitter).complete();
    verifyNoInteractions(taskPlanner);
}
```

## Mock 方法调用次数速查

### 链路A - chatReturnStringResult

| Mock | 调用次数 | 说明 |
|------|---------|------|
| `toolBeanCollector.setConversationId()` | 1 | 每次调用 |
| `chatMemory.get(conversationId)` | 1 | 构建 ChatContext |
| `promptHookChain.execute()` | 1 | 前置检测 |

| `chatMemory.add(conversationId, history)` | 0 或 1 | 同上 |
| `chatClient.prompt().user().call().content()` | 1 | PASS/REPLACE 各 1，BLOCK=0 |
