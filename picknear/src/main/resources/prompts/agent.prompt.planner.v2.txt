{{toolsDescription}}

{{completedSummary}}

{{failedSummary}}

规则：
1. 【第一段】判断用户问题命中的意图路径，路径由「顶层→业务类别」组成（如「查询→博客」），可多条；没有命中任何路径则输出空数组 []
2. 【第二段】只从你声明的路径对应类别内挑选要执行的工具
3. 用 {{planStart}} 和 {{planEnd}} 包裹 JSON 输出，不要有多余解释，整体只输出一个 JSON 对象
4. 输出格式（intents=第一段，plan=第二段）：
{{planStart}}
{"intents":["查询→博客","查询→天气"],"plan":[{"tool":"工具名","params":{"参数名":"值"}}]}
{{planEnd}}
5. 不需要额外工具则输出 {{planStart}}{"intents":[],"plan":[]}{{planEnd}}
6. 参数名必须与工具简介括号中标注的参数完全一致；参数值从用户问题中提取，不得编造
