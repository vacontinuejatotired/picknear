# 面试与展示材料

本目录只保存仍有长期人读价值的简历、讲解和设计模式材料。这里不是架构、接口、
配置或运维事实源；实现冲突时以代码、配置、运行行为、测试及对应模块当前文档为准。

## 当前材料

| 文档 | 用途 | 阅读时机 |
|---|---|---|
| [后端项目简历亮点](后端项目简历亮点.md) | 后端能力与量化亮点 | 准备简历或项目面试 |
| [项目亮点 - 上台讲解](项目亮点-上台讲解.md) | 分亮点讲解与追问准备 | 准备演示或答辩 |
| [项目亮点 - 讲解逐字稿](项目亮点-讲解逐字稿.md) | 可照读的短版讲稿 | 时间较紧的现场讲解 |
| [Agent 模块简历亮点](Agent模块简历亮点.md) | Agent 难点与工程收益 | 准备 AI 模块追问 |
| [Agent 模块设计模式](Agent模块设计模式.md) | 当前 Agent 代码中的模式映射 | 做设计复盘或架构讲解 |

## 阅读边界

1. 需要实现事实时，先读 [系统架构设计](../arch/系统架构设计.md)、
   [认证与登录设计](../auth/认证与登录设计.md) 或 [Agent 模块入口](../agent/README.md)。
2. 历史压测数字受环境与版本影响，对外引用前必须按当前代码复测并记录条件。
3. 审查、优化、压测和拆分过程不长期保留，需要追溯时从 Git 历史读取。
