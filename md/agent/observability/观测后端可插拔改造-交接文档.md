## 六、配置切换指南

### 切换观测后端（改两处）

**1. `application.yaml`**：`hmdp.ai-observability.backend.type`
```yaml
# langfuse（默认）/ jaeger / signoz / collector / console / noop
hmdp.ai-observability.backend.type: jaeger
```

**2. `management.otlp.tracing`**：endpoint + headers
```yaml
# Jaeger 本地
management.otlp.tracing.endpoint: http://localhost:4318/v1/traces
management.otlp.tracing.headers: {}

# Langfuse 云（现状）
management.otlp.tracing.endpoint: ${LANGFUSE_BASE_URL}/api/public/otel/v1/traces
management.otlp.tracing.headers:
  Authorization: Basic ${LANGFUSE_BASIC_AUTH}
  x-langfuse-ingestion-version: "4"
```

### 能力覆盖开关（调试/迁移用）

```yaml
hmdp.ai-observability:
  span-naming:
    semantic-encoding: auto   # auto=跟后端能力；true=强制编码；false=强制不编码
  chat-observation:
    include-content: true     # auto=跟后端能力；true/false 强制
```

### 切换 Prompt 远端仓库

```yaml
agent.prompt.repository.type: langfuse  # langfuse（默认）| none（走内置）
```
