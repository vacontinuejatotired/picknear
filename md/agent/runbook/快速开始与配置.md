# Agent 快速开始与配置

本文只负责 Agent 模块的启动、环境变量、接口验证和配置导航。架构、执行链路、SSE 事件细节和观测排障分别见对应专题文档。

## 1. 环境要求

- JDK 17+
- MySQL 8.0+
- Redis 6+
- DashScope API Key

## 2. 配置环境变量

后端运行配置位于 `picknear/picknear/.env`，该文件由 Compose 自动加载且已被 `.gitignore` 忽略。

最小 AI 配置示例：

```bash
DASHSCOPE_API_KEY=your-api-key

# 可选：启用 Langfuse 远端 Prompt 与观测
LANGFUSE_BASE_URL=
LANGFUSE_BASIC_AUTH=
```

数据库、Redis 和云服务凭据按 `application.yaml` 中的环境变量占位符补齐。

## 3. 启动

本地开发：

```bash
cd picknear/picknear
mvn spring-boot:run
```

使用已发布镜像时：

```bash
cd picknear/picknear
docker compose pull
docker compose up -d --no-build
```

不要在本机或 VM 执行 `docker build` / `docker compose build`。镜像由 CI/CD 构建并推送到 ACR。

服务默认监听 `http://localhost:8081`。

## 4. 验证 SSE

普通对话：

```bash
curl -N -X POST http://localhost:8081/agent/string/send \
  -H "Accept: text/event-stream" \
  -H "Authorization: Bearer <token>" \
  --data-urlencode "content=统计一下店铺数量"
```

CONFIRM 审批续流：

```bash
curl -N -X POST http://localhost:8081/agent/confirm \
  -H "Accept: text/event-stream" \
  -H "Authorization: Bearer <token>" \
  --data-urlencode "confirmId=cfm_xxx"
```

## 6. 修改配置时

1. 先修改 `application.yaml`，不要只在文档中改示例值。
2. 若新增配置组，只更新本文的职责和专题入口，不复制整段 YAML。
3. 若默认值影响启动、调用或排障，同步更新对应 Runbook。
4. 提交前验证变量名、默认值和服务启动结果。
